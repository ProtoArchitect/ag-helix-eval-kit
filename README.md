# AG-HELIX Evaluation Kit
Prepared exclusively for academic review (Prof. Juan David Ramirez).

## Usage
This kit contains a **pre-compiled** executable benchmark of the QTD4 extraction engine.
It demonstrates the O(N) alignment-free pathogen pipeline performance without exposing the underlying SWAR/F21 source code.

Target throughput: >0.30 GB/s on standard hardware.

```bash
# To run the benchmark:
chmod +x ./bin/ag_helix_eval_x64
./bin/ag_helix_eval_x64
```
